# Playbooks y skills

Aquí pueden guardarse playbooks, criterios de revisión y procedimientos específicos de Llamita Plus para que formen parte de la documentación del proyecto.

## Importante

Un archivo Markdown dentro de este repositorio no se convierte automáticamente en una skill ejecutable del catálogo de Codex. Para que una skill sea invocable por nombre debe registrarse en el entorno de skills correspondiente.

Por ahora esta carpeta sirve como biblioteca versionada de procedimientos. Cada playbook debería indicar:

- propósito;
- cuándo se aplica;
- entradas necesarias;
- pasos de inspección;
- criterios de detención;
- formato de salida;
- riesgos y límites.

La primera propuesta será un playbook de preflight para cambios grandes, pero se agregará después de que Hermes y el usuario acuerden su contenido.
